# ITA03 Mobile Computing – Assignment 4 (CO4)

Python demonstrations, figures and diagrams for Assignment 4. This folder includes design/architecture examples and engineering-validation models.

## Install
```bash
python -m pip install -r requirements.txt
```
Run from this folder:
```bash
python p1_task1_architecture.py
python p1_task2_push_messaging.py
python p1_task3_runtime_models.py
python p1_task4_security.py
python p1_task5_power.py
python p1_task6_ruralcare.py
python p2_task1_lifecycle.py
python p2_task2_parallel_benchmark.py
python p2_task3_runtime_benchmark.py
python p2_task4_security_audit.py
python p2_task5_energy_model.py
python p2_task6_tracking_policy.py
python diagrams.py
```
Images are saved under `figures/`.

## Tasks
Part I (Design): architecture, background messaging, runtime, security, power and RuralCare cross-platform design.
Part II (Engineering validation): OS/lifecycle observations, parallel-work benchmark, runtime benchmark, security regression checks, power model, tracking-policy simulation.

**Evidence disclaimer:** Reference/illustrative simulations are not measurements from a physical device. Replace example values with device logs/screenshots when your assignment requests actual measurements. Android-specific shell commands are listed in README and task scripts.
