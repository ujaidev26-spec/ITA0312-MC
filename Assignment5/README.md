# Assignment 5 – CO5: Mobile Computing

Android Application Features & Performance Engineering: source simulations, reproducible results, console outputs, and generated graphs.

Included in the package: `bgsim.py` (B1/B2), `feedsim.py` (B3 exact vs adaptive feed configuration), `videosim.py` (B4 heuristic vs exhaustive multimedia configuration), JSON results, text outputs, and figures.

Run with Python 3.9+. The scripts use only standard-library modules. Install `matplotlib` to generate plots. `feedsim.py` runs a quick scaling set by default; use `--full` for the original larger workload set (including n=800 and n=1500, which can take substantially longer).

These are model-based simulations, not measurements from a physical Android phone. Use Android Studio Profiler, Battery Historian, or Perfetto to capture device-specific evidence.
